# AI Research Agent (SerpApi Hackathon Project)

An autonomous search agent that fetches live Google Search data using the official SerpApi Python SDK.

## Features
- Real-time search query execution via SerpApi
- Extracts structured organic search titles, snippets, and links
- Built for the SerpApi India Hackathon (AI Agents Track)

## Prerequisites
- Python 3.9 or higher
- A free [SerpApi Account](https://serpapi.com)
